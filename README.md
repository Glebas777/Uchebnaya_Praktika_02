# my_os — Учебная операционная система

Учебный проект: ОС на Python 3.10+ с использованием SQLite в качестве файловой системы, журнала системных вызовов и реестра пользователей.

## Структура

- `src/` — исходный код (ядро, системные вызовы, оболочка, БД)
- `docs/` — проектная документация
- `db/` — база данных SQLite
- `tests/` — тесты
- `logs/` — журналы

## Запуск

```bash
python3 src/db.py        # создать БД
python3 -m src.shell     # запустить оболочку
